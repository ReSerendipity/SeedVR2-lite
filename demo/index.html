常见问题 (FAQ)
GitHub Pages 只能托管静态文件，无法运行 CUDA 模型。本演示站用本地模拟替代推理，用于体验完整界面与流程。
SeedVR2-3B / 7B / 7B-Sharp，支持 FP16 / FP8 与 INT8-ConvRot / MXFP8 / NVFP4 量化精度（3B 量化三件约 6.7 GB）；真实运行最低需要 8GB 显存（3B + FP8）。
为模拟「修复前」效果，左侧对同一张示例图做了 CSS 模糊/降饱和处理；真实模型会输出真正的修复结果。
每处理完一个文件自动保存 checkpoint，重启后检测未完成任务并恢复，已完成文件通过路径+大小+修改时间指纹跳过。
