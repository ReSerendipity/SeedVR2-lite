# SeedVR2 用户手册

> 版本：v1.5.1（Tauri 桌面版）
> 适用：Windows 10/11 x64

---

## 1. 系统要求

| 项目 | 要求 |
|---|---|
| 操作系统 | Windows 10 22H2 / Windows 11 22H2+（x64） |
| 显卡 | NVIDIA GPU（RTX 20/30/40/50 系列），**建议 8GB+ 显存** |
| 驱动 | NVIDIA 驱动 ≥ 525.60（支持 CUDA 12.8） |
| 内存 | 16GB 及以上 |
| 磁盘 | 完整版约需 10GB 空闲空间 |
| WebView2 | Windows 10/11 自带；精简版（LTSC）需手动安装 [WebView2 Runtime](https://developer.microsoft.com/microsoft-edge/webview2/) |

> 无 NVIDIA GPU 的机器可启动应用，但修复功能不可用（会提示模型加载失败）。

---

## 2. 安装步骤

### 2.1 下载

从 GitHub Releases 页面下载最新版本的便携分卷包（所有 `.001`/`.002`... 分卷 + `unpack_portable_bundle.ps1`）。

### 2.2 解压

1. 将**所有分卷**和 `unpack_portable_bundle.ps1` 放到同一个文件夹
2. 右键 →「使用 PowerShell 运行」`unpack_portable_bundle.ps1`（或在 PowerShell 中执行）
3. 脚本会自动合并分卷、校验 SHA256、解压出 `SeedVR2/` 文件夹

### 2.3 首次启动

进入解压出的文件夹，双击 `SeedVR2.exe` 启动。

> 首次启动会加载模型，可能需要 10~30 秒（取决于硬盘速度），请耐心等待启动画面。

## 3. 便携版使用说明

- **绿色便携**：所有文件在同一个目录，不写注册表、不装服务，可整体拷贝到 U 盘/其他电脑使用
- **启动**：双击 `SeedVR2.exe`
- **退出**：右键托盘图标 →「退出 SeedVR2」；点窗口右上角 X 会最小化到系统托盘（可在设置中改为直接退出）
- **数据位置**：用户配置保存在 `%APPDATA%\SeedVR2\`（config.json / window_state.json），不影响便携目录
- **日志位置**：`SeedVR2\app\logs\`（排查问题时可查看）

### 3.1 系统托盘

| 操作 | 效果 |
|---|---|
| 左键单击托盘图标 | 显示 / 隐藏主窗口 |
| 右键 → 显示主窗口 | 显示窗口 |
| 右键 → 隐藏到托盘 | 隐藏窗口 |
| 右键 → 打开日志目录 | 打开日志文件夹 |
| 右键 → 检查更新 | 手动检查新版本 |
| 右键 → 退出 SeedVR2 | 停止后端服务并退出 |

### 3.2 文件拖拽

- 将**图片/视频文件**直接拖入「图片修复」页面的上传区 → 自动载入并开始修复
- 将**文件夹**拖入 → 自动切换批量模式并扫描该目录
- 首次拖拽会弹出目录授权提示，允许后可批量处理该目录下的文件

## 4. 基本操作

### 4.1 单张图片修复

1. 进入「图片修复」页面
2. 点击上传区选择图片，或直接拖入
3. 选择参数：分辨率（如 2048）、双重放大开关、任务类型
4. 点击「开始修复」
5. 修复完成后可预览、下载结果

### 4.2 批量修复

1. 切换到「批量」模式
2. 选择/输入要处理的文件夹
3. 点击「扫描文件夹」确认文件列表
4. 点击「开始批量修复」

### 4.3 历史记录

- 每次修复任务都会记录在历史列表中
- 可下载历史结果文件、删除记录
- 输出文件被清理后，下载按钮自动置灰（不再报 404）

### 4.4 设置

- **精度（precision）**：可在 fp16 / fp8 / mxfp8 / int8 / nvfp4 间选择。默认 mxfp8（内置模型精度），平衡画质与速度
- **精度切换**：切换后自动重新加载对应精度的模型（需本地存在对应权重文件）

## 5. 模型管理

### 5.1 内置模型

完整版已内置：

| 文件 | 用途 |
|---|---|
| `model/seedvr2_3b_mxfp8.safetensors`（~3.3GB） | 主模型（mxfp8 精度） |
| `model/ema_vae_fp16.safetensors`（~478MB） | VAE 解码器 |
| `model/pos_emb.pt` / `model/neg_emb.pt` | 位置嵌入 |

### 5.2 替换 / 添加模型

- 模型文件放在 `SeedVR2\app\model\` 目录下
- 文件名需符合约定（如 `seedvr2_3b_fp16.safetensors`、`seedvr2_3b_fp8_e4m3fn.safetensors`、`seedvr2_3b_mxfp8.safetensors` 等）
- 在设置中切换对应精度即可使用
- **模型更新不需要升级应用**，替换文件后重启应用即可

### 5.3 支持精度与文件命名

| 精度 | 权重文件名 |
|---|---|
| fp16 | `seedvr2_ema_3b_fp16.safetensors` |
| fp8 | `seedvr2_ema_3b_fp8_e4m3fn.safetensors` |
| mxfp8（默认） | `seedvr2_3b_mxfp8.safetensors` |
| int8 | `seedvr2_3b_int8_convrot.safetensors` |
| nvfp4 | `seedvr2_3b_nvfp4.safetensors` |

> 加载时会按 fp16 → fp8 → mxfp8 → int8 → nvfp4 顺序自动回退到本地可用的模型，无需手动指定。

## 6. 更新说明

### 6.1 应用更新（增量）

- 启动后会自动检查更新（静默，无更新不打扰）
- 有更新时，任务栏托盘图标出现提示，或手动右键托盘 →「检查更新」
- 更新对话框显示：当前版本 / 最新版本 / 包大小 / 变更日志
- 点击「立即更新」→ 自动下载 → 校验 → 替换 → 重启，全程无需手动操作
- 更新失败会自动回滚到旧版本，应用不受影响

> 增量更新只更新**应用代码**（约 10MB），**不包含** Python 运行时和模型权重——依赖与模型由安装包提供，用户自行替换模型。

### 6.2 完整升级（整包）

- 如需更新运行时或模型，请下载新版完整分卷包，按第 2 节重新解压
- 用户配置（`%APPDATA%\SeedVR2\`）保留，历史记录如有需要请自行备份

## 7. 常见问题（FAQ）

**Q1：启动很慢，卡在启动画面？**
首次启动需加载模型（10~30 秒）。若超过 2 分钟，请查看 `app\logs\` 下的日志，或用托盘「打开日志目录」。

**Q2：提示「模型文件不存在」？**
检查 `app\model\` 下是否有对应精度的权重文件。完整版已内置 mxfp8 模型，缺文件时请重新解压。

**Q3：提示「服务启动超时」？**
多为端口被占用或 Python 运行时损坏。尝试：右键托盘退出 → 重新双击 `SeedVR2.exe`。仍失败请查看日志。

**Q4：更新失败？**
更新会自动回滚，应用不受影响。常见原因：磁盘空间不足、网络中断、无写权限（如安装在 Program Files）。可稍后重试，或下载完整包手动升级。

**Q5：没有 GPU / 显存不足？**
应用可启动但修复功能不可用。需 NVIDIA GPU（建议 8GB+ 显存）运行。

**Q6：双击没反应？**
确认已解压完整（所有分卷）、WebView2 已安装、杀毒软件未拦截。可查看 `app\logs\` 日志。

**Q7：如何备份数据？**
历史记录数据库位于 `app\data\` 目录；用户配置在 `%APPDATA%\SeedVR2\`。整体拷贝即可备份。

## 8. 卸载方法

便携版无安装程序，直接删除 `SeedVR2/` 文件夹即可卸载。如需清理用户数据，一并删除 `%APPDATA%\SeedVR2\` 目录。
