## 改动点 ②：更新检查支持 prerelease（按版本号取最高，而非 latest）

**文件**：`desktop\src-tauri\src\updater.rs`

将 `do_check` 的 Github 分支（约 L361-367）从"拉 latest 单条"改为"拉列表取版本最高"：

```rust
UpdateSource::Github { owner, repo } => {
    // 拉最近若干条 release（含 prerelease），取语义版本最高的一条（跳过 draft）
    let releases = fetch_releases_list(&client, owner, repo, 10).await?;
    let latest = releases
        .iter()
        .filter(|r| !r.draft && r.tag_name.starts_with('v'))
        .max_by(|a, b| {
            parse_semver(&normalize_version(&a.tag_name))
                .cmp(&parse_semver(&normalize_version(&b.tag_name)))
        })
        .ok_or_else(|| anyhow!("未找到任何已发布版本"))?;
    let version = normalize_version(&latest.tag_name);
    // ...以下逻辑不变（version 比较 / resolve_assets / fetch_sha256）
}
```

新增辅助函数（参照 `fetch_github_release` 的请求头写法）：

```rust
/// 拉取 release 列表（per_page=N），返回数组
async fn fetch_releases_list(
    client: &reqwest::Client, owner: &str, repo: &str, per_page: u32,
) -> Result<Vec<serde_json::Value>> {
    let url = format!(
        "https://api.github.com/repos/{owner}/{repo}/releases?per_page={per_page}"
    );
    let resp = client
        .get(&url)
        .header("Accept", "application/vnd.github+json")
        .header("User-Agent", "SeedVR2-Desktop")
        .send()
        .await
        .map_err(|e| anyhow!("GitHub 请求失败: {e}"))?;
    if !resp.status().is_success() {
        return Err(anyhow!("GitHub 返回 {}", resp.status()));
    }
    resp.json().await.map_err(|e| anyhow!("解析 release 列表失败: {e}"))
}
```

> 注意：`fetch_github_release` 内部已有请求头构造，可抽公共函数避免重复；`parse_semver` / `normalize_version` 均为现有函数。
> 若只想要"正式版优先、prerelease 兜底"：`max_by` 改为先比 `!prerelease` 再比版本号即可（可按产品策略二选一，默认推荐"版本号最高含 prerelease"）。

**验证**：发布一个 prerelease（如 v1.5.3-rc1）→ 本地 1.5.2 检查更新应能发现它。
