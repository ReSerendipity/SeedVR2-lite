# SeedVR2 开发者指南

> 面向 SeedVR2-lite 仓库的开发者。覆盖开发环境、Tauri 桌面壳、打包发布与更新包制作。

---

## 1. 开发环境搭建

| 工具 | 版本要求 | 说明 |
|---|---|---|
| Windows | 10/11 x64 | 开发/目标平台 |
| Rust | stable（≥1.70） | `rustup component add clippy` 安装静态检查 |
| Node.js | ≥ 20（建议 22） | 运行 Tauri CLI（`@tauri-apps/cli`） |
| Python | 3.12 | 项目后端运行时 |
| NVIDIA GPU + 驱动 | ≥ 525.60 | CUDA 12.8+，模型推理必需 |

### 1.1 Python 环境

```powershell
python -m venv .venv
.\.venv\Scripts\pip install -r requirements.txt
# torch（CUDA 版，与 .venv 当前版本一致：2.13.0+cu132）
.\.venv\Scripts\pip install torch torchvision torchaudio --index-url https://download.pytorch.org/whl/cu132
```

### 1.2 Rust / Node 环境

```powershell
rustup toolchain install stable-msvc
rustup component add clippy
# desktop/ 下安装 Tauri CLI（package.json 已声明 devDependency）
cd desktop
npm install
```

### 1.3 模型文件

模型放在项目根 `model/` 目录（文件名见《用户手册》§5.3）。至少需要：
- `seedvr2_3b_mxfp8.safetensors`（主模型，mxfp8）
- `ema_vae_fp16.safetensors`、`pos_emb.pt`、`neg_emb.pt`

## 2. 项目结构说明

```
SeedVR2-lite/
├── app/                     # FastAPI 后端应用
│   └── integrated_app/      #   应用主体（routes/engines/model_manager/security...）
├── model/                   # 模型权重（不提交仓库）
├── scripts/                 # 构建/发布/工具脚本
├── desktop/                 # Tauri v2 桌面壳
│   ├── src/                 #   前端（index.html 启动页 + desktop-bridge.js 桥接）
│   └── src-tauri/
│       ├── src/             #   Rust 模块（见下）
│       ├── tauri.conf.json  #   应用配置
│       └── capabilities/    #   IPC 权限
├── docs/tauri-migration/    # 桌面化迁移计划与 AI 分工文档
├── dist/tauri-release/      # Tauri 发布产物（staging / bundles）
├── start_portable.py        # 便携启动脚本（Tauri 壳调用）
├── config.yaml              # 应用配置
└── .venv/                   # 开发 Python 环境（不提交）
```

### 2.1 Tauri Rust 模块

| 模块 | 职责 |
|---|---|
| `main.rs` | 入口：单实例/插件/命令注册/窗口事件/watchdog/退出兜底 |
| `python_process.rs` | Python 子进程生命周期 + **应用目录/运行时解析**（`resolve_app_dir` / `resolve_runtime_dir`） |
| `port_manager.rs` | 随机空闲端口分配 |
| `health_check.rs` | `/api/system/health` 就绪轮询 |
| `tray.rs` | 系统托盘（左键切换/右键菜单/忙闲提示/更新徽标） |
| `window.rs` | 窗口状态记忆/外链拦截/标题联动/关闭到托盘 |
| `notification.rs` | Windows Toast（前台抑制/声音开关） |
| `drag_drop.rs` | 文件拖拽白名单 + `read_dragged_file` |
| `config.rs` | `%APPDATA%/SeedVR2/` 配置原子读写（含 UTF-8 BOM 兼容） |
| `updater.rs` | 增量更新：检查/下载/SHA256/原子换载/回滚 |

### 2.2 关键路径解析（重要）

```rust
resolve_app_dir():
  1. 优先 exe 旁 app/（含 start_portable.py）→ 打包后
  2. 回退 CARGO_MANIFEST_DIR 上溯项目根 → 开发模式

resolve_runtime_dir(app_dir):
  1. app_dir/runtime/          → 打包后侧载运行时
  2. app_dir/.venv/Scripts     → 开发模式
  3. 上两级 .venv/Scripts      → 历史布局
  4. PATH 中 python            → 兜底
```

> ⚠️ `resolve_app_dir` 必须**优先检查 exe 旁 app/**，不能先匹配编译路径——否则 release 版在开发机/用户机都会错误解析（历史教训，已修复）。

## 3. 开发模式运行

```powershell
# 方式 A：直接跑 Python 后端（浏览器访问）
.\.venv\Scripts\python.exe start_portable.py --port 7870

# 方式 B：Tauri 壳（自动拉起 Python，WebView 加载）
cd desktop
npm run tauri dev

# 方式 C：debug 版壳直接运行（同 B 效果）
cd desktop/src-tauri
cargo run
```

Tauri 壳开发模式下自动使用项目根 `.venv` 作为运行时，端口随机分配，WebView 加载 `http://127.0.0.1:随机端口`。

## 4. 打包流程

### 4.1 构建 Tauri release 壳

```powershell
cd desktop/src-tauri
cargo build --release
# 产物：target/release/seedvr2-desktop.exe
```

> 壳本体约 16MB，**不含**应用代码/运行时/模型（这些走分卷 payload）。

### 4.2 组装发布目录

```powershell
# 目标布局（staging/）：
#   SeedVR2.exe          ← Tauri 壳
#   app/                 ← 应用根
#     start_portable.py
#     app/  common/  model_lib/  configs_3b/  data/   ← 应用代码
#     runtime/           ← 侧载 Python 运行时（python.exe + Lib + site-packages）
#     model/             ← 模型权重
#     config.yaml
```

组装来源（任选）：
- 从上一版完整分卷解压 `app/`，替换 `SeedVR2.exe` 与需要更新的应用代码
- 或从项目根复制应用代码 + 复制已验证的运行时 + 复制模型

**运行时准备**（不依赖系统 Python）：
- 复制完整 Python 3.12 安装目录（含 `python.exe`）→ 清空 `PYTHONHOME/PYTHONPATH` 验证独立运行
- 将 `.venv\Lib\site-packages` 合并进运行时 `Lib/site-packages`（含 CUDA torch）
- 验证：`runtime\python.exe -c "import torch; print(torch.cuda.is_available())"`

### 4.3 一键发布打包

```powershell
powershell -ExecutionPolicy Bypass -File scripts\release_tauri.ps1 -Version 1.5.1
```

产出（`dist/tauri-release/bundles/`）：
- `SeedVR2-Desktop-v1.5.1-win-x64.7z.001/.002/...`（每卷 ≤1900MB）
- `SHA256SUMS.txt`、`manifest.json`、`upload-list.txt`
- `unpack_portable_bundle.ps1`、`portable_bundle_lib.ps1`（解压辅助）

## 6. 更新包制作规范（增量更新）

增量更新**只替换应用代码**（`app/` 内除 `runtime/`、`model/` 的内容），不更新运行时与模型。

### 6.1 打包规范

```
app-v1.5.2.zip          ← zip 根 = app/ 目录内容（禁止嵌套一层）
app-v1.5.2.zip.sha256   ← 内容 "<hex>  <filename>"
```

zip 内必须含 `version.json`：

```json
{
  "version": "1.5.2",
  "release_date": "2026-09-10",
  "minimum_shell_version": "1.0.0",
  "changelog": "修复 xxx；优化 yyy"
}
```

### 6.2 版本比较

- 用 semver 规则（剥 `v` 前缀），禁止字符串比较
- 本地版本无效时静默不更新
- `minimum_shell_version`：声明兼容的壳最低版本（壳结构变化时递增）

### 6.3 执行序列（壳内已实现）

```
下载 → SHA256 校验 → 解压 app.new/ → 校验 version.json → 停 Python(taskkill /T)
→ app/ → app.bak/ → app.new/ → app/ → 重启 + 健康检查 → 成功删备份/失败回滚
```

任一步失败自动回滚（旧版 `app.bak/` 还原），应用不损坏。

### 6.4 更新源

- 默认 GitHub：`ReSerendipity/SeedVR2-lite` releases
- 自定义服务器：`%APPDATA%/SeedVR2/config.json` 的 `update_source`（`{"Custom":{"url":...}}`）

## 7. 调试技巧

### 7.1 查看日志

- 应用日志：`app\logs\`（Python）与 Rust `env_logger`（设置 `RUST_LOG=debug`）
- 用户配置：`%APPDATA%\SeedVR2\{config.json,window_state.json}`

### 7.2 测试命令

```powershell
cd desktop/src-tauri
cargo test          # 33 项单测（更新器/窗口/托盘/拖拽/配置/端口）
cargo clippy --all-targets -- -D warnings
```

### 7.3 更新流程本地调试

用本地 HTTP 服务器模拟更新源（`check_custom_source_against_local_server` 单测即此思路）：
1. 起 `python -m http.server 8000` 提供 `update.json` 与 `app-vX.Y.Z.zip`
2. 配置 `update_source = {"Custom":{"url":"http://127.0.0.1:8000/update.json"}}`
3. 托盘「检查更新」→ 触发下载/换载/回滚调试

### 7.4 常见问题

| 现象 | 排查 |
|---|---|
| 壳启动但页面空白 | 检查健康检查是否通过（日志"服务就绪"）；端口是否被占 |
| Python 启动即退出 | 看 `app/logs/python_*.log`；确认运行时完整 |
| 更新后功能异常 | 更新自动回滚后仍异常 → 手动下载完整包重装 |
| 壳误解析到项目根 | 确认 exe 旁有 `app/start_portable.py`（resolve 顺序问题） |
