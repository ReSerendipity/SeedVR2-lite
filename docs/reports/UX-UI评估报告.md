### ISSUE-002: SSE 连接偶发失败，状态更新不及时

| 字段 | 值 |
|------|-----|
| **严重程度** | 🔴 高 |
| **类别** | 功能性 / 性能 |
| **页面** | 全站（影响系统状态、进度更新） |
| **相关文件** | [app.js](file:///c:/Users/HONOR/Seedvr2/bin/integrated_app/static/js/app.js) |

**问题描述**

从网络请求日志中观察到 SSE (Server-Sent Events) 连接偶尔会失败（`net::ERR_ABORTED`），虽然会自动重连，但在重连期间状态更新会中断。对于长时间运行的修复任务，这可能导致进度显示不准确。

**当前表现**
- SSE 连接偶发中断，控制台显示 `net::ERR_ABORTED`
- 中断期间进度条和系统状态不更新
- 重连后数据恢复正常

**预期表现**
- SSE 连接更稳定，减少意外中断
- 连接中断时有明确的视觉提示
- 自动重连机制更智能（指数退避）
- 提供降级方案（如轮询）确保状态更新不中断

**优化建议**

```javascript
// 建议：改进 SSE 重连策略
class SSEManager {
    constructor(url) {
        this.url = url;
        this.retryDelay = 1000;
        this.maxRetryDelay = 30000;
        this.retryCount = 0;
        this.isConnected = false;
    }

    connect() {
        this.source = new EventSource(this.url);
        
        this.source.onopen = () => {
            this.isConnected = true;
            this.retryDelay = 1000;
            this.retryCount = 0;
            this.notifyConnectionStatus(true);
        };

        this.source.onerror = () => {
            this.isConnected = false;
            this.notifyConnectionStatus(false);
            // 指数退避重连
            setTimeout(() => this.reconnect(), this.retryDelay);
            this.retryDelay = Math.min(this.retryDelay * 2, this.maxRetryDelay);
            this.retryCount++;
        };
    }

    notifyConnectionStatus(connected) {
        // 显示连接状态指示器
        const indicator = document.getElementById('sseStatusIndicator');
        if (indicator) {
            indicator.style.display = '';
            indicator.className = connected ? 'sse-status connected' : 'sse-status reconnecting';
        }
    }
}
```

**技术实现方向**
1. 实现指数退避的重连策略
2. 添加连接状态指示器（右下角系统状态栏）
3. SSE 中断时降级为轮询（每 2 秒）
4. 优化服务端 SSE 心跳机制（目前 30 秒间隔可缩短）
5. 添加重连次数限制和最终失败提示

**预期效果**
- SSE 连接稳定性提升 50%
- 用户明确知晓连接状态
- 状态更新延迟 < 2 秒

   - 考虑使用卡片式切换

2. **模式引导说明**
   - 在标签页下方添加一行简短说明
   - 新用户首次访问时显示引导提示

3. **URL 参数支持**
   - 支持 `/restore?mode=batch` 直接跳转批量模式
   - 模式切换时更新 URL，便于分享和刷新保持状态

**技术实现方向**
1. 优化标签页 CSS 样式，增加视觉权重
2. 实现 URL 哈希或查询参数同步模式状态
3. 添加新手引导组件（可关闭）
4. 考虑在首页添加"批量修复"入口

**预期效果**
- 批量修复功能发现率提升 80%
- 用户能更快找到适合自己的工作模式
- 刷新页面后保持当前模式
