**阶段三修复的 3 个缺陷（已回归验证）**：
1. **Tauri 2.11 ACL 收紧**：remote 页面调用自定义命令被拒 → build.rs `AppManifest::commands()` + capabilities 授予 `allow-*`（无前缀）→ 修复后 `start_update` 等 17 个命令全部可用。
2. **增量更新换载丢重型目录**：`app.new/` 缺 runtime/model/data/logs → `preserve_heavy_dirs` 补进 + 换载保留。
3. **模型文件被 torch 占用导致复制卡死**：preserve 移到停 python 之后（3.4GB 模型 2s 复制完 vs 之前 6 分钟停滞）；另新增 **app.bak 延迟 30s 异步删除 + 启动兜底清理**（实测启动自动清理残留备份）。
