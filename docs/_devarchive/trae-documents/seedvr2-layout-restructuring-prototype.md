# SeedVR2 UI 布局重构 HTML 原型方案

## 一、当前 UI 问题诊断（基于 92 张截图分析）

### 1.1 首页问题
- **Bento 网格不平衡**：「开始修复」卡片占 ~60% 宽度，「系统状态」占 ~40%，「历史记录」孤立在下方第三行，视觉重心偏左
- **Hero 渐变色不一致**：浅色主题下 Hero 渐变呈现橙色调，与紫色品牌主色冲突
- **移动端标题过大**：`SeedVR2 便携式视频/图像修复工具箱` 在 375px 屏幕上换行 3 行，占据过多垂直空间
- **系统状态概览被截断**：底部运行时间和操作卡片在桌面端就被 status bar 遮挡

### 1.2 修复页问题
- **左侧面板拥挤**：上传区 + 文件夹路径 + 三个操作按钮全部堆叠在窄侧边栏内，间距不足
- **工作流引导过小**：中央区域的三步引导（上传->处理->完成）在大屏幕上显得空旷，但内容太少
- **平板端退化严重**：768px 下三栏变单列，文件上传、工作流引导、参数面板全部纵向堆叠，页面过长
- **右侧参数面板**：高级参数折叠按钮不明显，用户难以发现

### 1.3 历史记录问题
- **表格头部未翻译**：`HISTORY.PREVIEW` 等英文硬编码显示
- **移动端筛选器堆叠**：搜索框、类型筛选、状态筛选各自占满一行，工具栏高度过大
- **空状态设计良好**，但有记录时表格在小屏幕上水平溢出

### 1.4 系统状态问题
- **移动端页面过长**：GPU 信息、模型状态、系统内存、运行信息四张卡片全部纵向堆叠
- **GPU 错误状态占空间大**：`CPU 模式不受支持` 警告在 GPU 不可用时占用大量垂直空间
- **浅色主题下环形进度**：内存使用率的橙色环形与紫色品牌色不协调

### 1.5 设置页问题
- **大量空白**：路径配置表单只有两个字段，下方大面积空白
- **左侧标签导航**：移动端变为顶部标签后，标签间距过大

### 1.6 全局问题
- **底部状态栏冲突**：移动端 status bar 与页面内容重叠
- **导航栏快捷键标签**：`Alt+1` 等标签在小屏幕上溢出或被隐藏
- **浅色主题对比度**：部分文字在浅紫背景上对比度不足

## 二、3 个重构方向

### 方向 A：「指挥台」- 信息密集型布局
**核心理念**：借鉴专业工具（DaVinci Resolve / Blender）的面板化设计，最大化信息密度和操作效率。

**视觉特征**：
- 深色为主的沉浸式界面，低饱和度紫色主色 `#6366f1`
- 左侧窄导航栏（48px 图标），hover 展开为 200px 文字面板
- 顶部状态指示条（32px），实时显示 GPU/VRAM/任务状态
- 卡片使用 6px 圆角，1px 半透明边框，无阴影或极轻阴影
- 数据区域使用 JetBrains Mono 等宽字体
- 表格行高 36px，紧凑排列

**各页面布局**：
- **首页**：顶部指标条 + 2x2 仪表板网格（GPU/内存/模型/任务）+ 底部最近任务列表
- **修复**：三栏等宽布局：文件列表(200px) + 预览画布(自适应) + 参数面板(260px)，底部浮动操作栏
- **历史**：全宽紧凑表格，行高 36px，支持列宽拖拽
- **系统状态**：顶部 4 指标卡片 + 下方 2 列详情面板
- **设置**：左侧折叠标签 + 右侧分组表单，底部固定操作栏

### 方向 B：「创作台」- 工具优先型布局
**核心理念**：借鉴 Figma / VS Code 的面板系统，强调可折叠性和工作区最大化。

**视觉特征**：
- 紫色品牌色保留 `#7c6cf0` + 珊瑚色点缀 `#ff7f50`
- 左侧 56px 图标栏（仅图标），hover 显示 tooltip
- 顶部面包屑 + 页面标题栏（48px）
- 卡片 12px 圆角，柔和 `box-shadow`，hover 时微微上浮
- 毛玻璃导航栏（`backdrop-filter: blur(12px)`）
- 工作流步骤指示器（上传->处理->完成）

**各页面布局**：
- **首页**：居中 Hero（渐变文字标题）+ 3 等宽快速入口卡片 + 系统状态 4 格概览
- **修复**：可折叠三面板（文件 260px / 画布 / 参数 300px），顶部步骤条，面板可独立收起为图标
- **历史**：搜索栏 + 视图切换（表格/网格），网格视图显示预览缩略图卡片
- **系统状态**：2x2 大尺寸环形进度卡片 + 下方详情网格
- **设置**：左侧图标+文字标签导航 + 右侧卡片分组表单

### 方向 C：「流光」- 现代极简型布局
**核心理念**：借鉴 Linear / Raycast 的流体设计，强调内容流动性和视觉呼吸感。

**视觉特征**：
- 渐变背景（深紫 `#0f0a1e` 到深蓝 `#1a1035`），浅色主题使用淡紫渐变
- 顶部 56px 玻璃导航栏，无侧边栏
- 紫罗兰主色 `#a78bfa` + 暖橙点缀 `#fb923c`
- 卡片 16px 圆角，玻璃拟态（`backdrop-filter: blur(20px)`），半透明边框 `1px solid rgba(255,255,255,0.08)`
- 标题使用渐变文字（`background-clip: text`）
- 内容区居中 `max-width: 1040px`，大量留白
- 页面间使用圆点导航器（Dot Navigation）

**各页面布局**：
- **首页**：居中大标题渐变文字 + 状态徽章 + 玻璃快速操作卡片 + 玻璃状态仪表板
- **修复**：垂直单列工作流：步骤指示器 + 玻璃上传卡 + 玻璃参数折叠面板 + 全宽预览区
- **历史**：居中玻璃搜索栏 + 时间线视图（每条记录为玻璃卡片，左侧时间线连接）
- **系统状态**：居中 3 个大型玻璃指标卡（GPU/RAM/模型）+ 下方玻璃详情面板
- **设置**：居中玻璃 Tab 切换 + 玻璃卡片表单分组

## 三、响应式策略（三方向通用）

### 断点定义
```
576px  → 手机（<576px 为小手机）
768px  → 平板竖屏
992px  → 平板横屏/小笔记本
1200px → 桌面
1600px → 超宽屏
```

### 各方向响应式适配

**方向 A（指挥台）**：
- `<576px`：图标栏隐藏，汉堡菜单，首页 1 列，修复页单列纵向
- `576-768px`：图标栏 40px，首页 2 列，修复页文件+预览合并
- `768-992px`：图标栏 48px，修复页三栏完整
- `>992px`：标准布局

**方向 B（创作台）**：
- `<576px`：图标栏隐藏，顶部标签变下拉，修复页单列
- `576-768px`：图标栏 40px，文件面板默认折叠
- `768-992px`：图标栏 56px，文件面板展开，参数面板折叠
- `>992px`：完整三面板

**方向 C（流光）**：
- `<576px`：导航栏简化，内容 padding 减小，卡片堆叠
- `576-768px`：导航完整，内容 100% 宽度
- `>992px`：内容居中 max-width 1040px

## 四、单文件 HTML 架构

### 4.1 CSS 组织
```css
/* === 基础重置 === */
/* === 方向 A 变量 (dark + light) === */
/* === 方向 B 变量 (dark + light) === */
/* === 方向 C 变量 (dark + light) === */
/* === 全局控制栏样式 === */
/* === 方向 A 布局样式 === */
/* === 方向 B 布局样式 === */
/* === 方向 C 布局样式 === */
/* === 响应式媒体查询 === */
/* === 动画 === */
```

### 4.2 HTML 结构
```
<body data-direction="a" data-theme="dark">
  <!-- 顶部浮动控制栏 -->
  <div id="controlBar">
    <div class="direction-tabs">  <!-- A/B/C 方向切换 -->
    <div class="theme-toggle">   <!-- 深色/浅色 -->
    <div class="viewport-info">  <!-- 当前视口提示 -->
  </div>

  <!-- 方向 A -->
  <div id="dir-a" class="direction active">
    <nav class="a-rail">...</nav>
    <div class="a-metrics">...</div>
    <main>
      <div class="page" data-page="home">...</div>
      <div class="page" data-page="restore">...</div>
      <div class="page" data-page="history">...</div>
      <div class="page" data-page="system">...</div>
      <div class="page" data-page="settings">...</div>
    </main>
  </div>

  <!-- 方向 B -->
  <div id="dir-b" class="direction">...</div>

  <!-- 方向 C -->
  <div id="dir-c" class="direction">...</div>
</body>
```

### 4.3 JS 切换逻辑
- `switchDirection(id)`：切换方向容器显示
- `switchPage(dir, page)`：切换当前方向内的页面
- `switchTheme(theme)`：切换 data-theme 属性
- 所有数据使用硬编码模拟，中文填充

## 六、关键约束

- 单文件 HTML，纯 CSS + 原生 JS，无外部框架
- 仅使用 CDN：Google Fonts（Inter, JetBrains Mono）+ Bootstrap Icons
- CSS 变量通过 `data-direction` + `data-theme` 双层切换
- 模拟数据使用中文，覆盖所有页面的核心交互状态
- 目标文件大小控制在合理范围内（各方向 CSS 不超过 1200 行）
